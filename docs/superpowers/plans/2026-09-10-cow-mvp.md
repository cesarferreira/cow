# CoW MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete macOS/Linux `cow` library and CLI with native CoW cloning, safe fallback copying, inspection, structured output, tests, and measured documentation.

**Architecture:** A single Cargo package exposes a small typed library while the binary remains a rendering and argument-parsing layer. A transactional coordinator selects a private platform backend, clones into a random sibling path, and atomically renames it; portable traversal owns metadata and symlink semantics shared by Linux reflinks and regular copies.

**Tech Stack:** Rust 2024, clap, serde/serde_json, thiserror, libc, walkdir, filetime, rand, signal-hook, assert_cmd, predicates, tempfile.

**Spec:** `docs/superpowers/specs/2026-09-10-cow-design.md`

## Global Constraints

- Support macOS and Linux from one public API.
- Never shell out for native cloning.
- Never follow symlinks or overwrite an existing destination.
- `Auto` may fall back only for capability failures; `Cow` never falls back; `Copy` never probes CoW.
- Publish only benchmark measurements reproduced on the current host with methodology disclosed.
- Do not add Git behavior, persistent state, force deletion, exclusions, progress UI, Windows support, `doctor`, or a benchmark subcommand.
- Every production behavior is introduced by a failing test and a verified red-green cycle.

### Task 4: Native macOS and Linux CoW backends

**Files:**
- Create: `src/platform/mod.rs`, `src/platform/macos.rs`, `src/platform/linux.rs`
- Modify: `src/tree.rs`, `src/lib.rs`, `src/error.rs`
- Create: `tests/cow_backend.rs`

**Interfaces:**
- Produces: `platform::clone_cow(source, destination) -> Result<CloneStrategy, BackendError>` and a capability classification distinguishing unsupported/cross-device failures from fatal I/O.

- [ ] **Step 1: Write failing backend tests**

Test that `StrategyPreference::Cow` either returns the platform-native strategy and produces an independent equivalent clone, or returns `CowError::CowUnsupported`; it must never return `Copy`. Test that `Auto` produces an equivalent clone regardless of current filesystem capability.

```rust
#[test]
fn required_cow_never_silently_copies() {
    let fixture = TreeFixture::small();
    match clone_dir(fixture.source(), fixture.destination(), CloneOptions::require_cow()) {
        Ok(result) => assert!(result.strategy.is_cow()),
        Err(error) => assert!(matches!(error, CowError::CowUnsupported { .. })),
    }
}
```

- [ ] **Step 2: Verify red**

Run `cargo test --test cow_backend -- --nocapture`. Expected: native-strategy expectations fail because the backend is absent.

- [ ] **Step 3: Implement macOS cloning**

Call `libc::clonefile` with no-follow semantics and map `ENOTSUP`, `EXDEV`, and equivalent capability errors to `BackendError::Unsupported`. Preserve all other errno values as fatal typed I/O. Keep the module behind `cfg(target_os = "macos")`.

- [ ] **Step 4: Implement Linux reflinks**

Reuse traversal with a regular-file callback that opens the source read-only, creates the destination exclusively, and calls `ioctl(destination_fd, FICLONE, source_fd)`. Map `EOPNOTSUPP`, `ENOTTY`, `EXDEV`, and `EINVAL` from the clone ioctl to unsupported; keep other errors fatal. Keep the module behind `cfg(target_os = "linux")`.

- [ ] **Step 5: Implement coordinator fallback**

For `Auto`, attempt the native backend in one guard; on `Unsupported`, reset the private destination and rerun the entire operation with copy. For `Cow`, return `CowUnsupported`. For `Copy`, call the portable backend directly. Commit only after `DestinationGuard::commit` succeeds.

- [ ] **Step 6: Verify green on the host filesystem**

Run `cargo test --test cow_backend -- --nocapture`. Expected: assertions pass and output explicitly states whether native verification ran or was skipped due to `CowUnsupported`.

- [ ] **Step 7: Commit**

Commit as `feat: add native copy on write backends`.
